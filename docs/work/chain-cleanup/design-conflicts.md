# Design темы chain-cleanup: конфликты, дубли, лишнее

> Раздел 2, одобрен пользователем 2026-10-11: что мешает и как будет.

| Что мешает | Как будет |
|---|---|
| План ссылается на требование номером, исполнитель требований не видит | Точное значение пишется в план словами; исполнитель остаётся без карточек требований |
| `saway` стоит на «ждёт ручной проверки» | У среза без зависимых это не остановка, как в `swork`; правится только `saway` |
| Шапка плана и срез упираются в предел карточки | Переросшие делятся по правилу вики, `swork` читает части и передаёт их исполнителю |
| `splan` не называет `task.md`, `examples.md`, `design.md`, карточки решений | Читает все карточки темы по её индексу |
| Причина остановки и отклонённые находки живут только в чате | Пишутся в «Ход исполнения» до остановки и до показа отчёта; `splan` при возврате его читает |
| План можно одобрить без независимой проверки | Вход с фазой «план записан» сначала смотрит, пройдена ли проверка; нет — идёт на неё |
| Срез-перестройка встаёт на входе в `swork` | `splan` помечает срез, не меняющий поведения; для него зелёная проверка до правок — не остановка |
| Совет «новая сессия» при плане, который лежит только в чате | Совет даётся, только когда итог записан в папку темы |
| Снятому блокирующему вопросу нет места в плане | В шапке плана появляется раздел «Допущения»; мёртвое правило об отложенных вопросах уходит |
| Малый путь: запреты ревью стоят в одном сообщении с просьбами сверки | Задания разведены так, что запрет действует только внутри своего задания |
| «Откатить всё» оставляет снимок и записи хода | Откат убирает и их: повторный запуск начинается с чистого |
| «Исполнитель» значит и подагента, и `swork` | В `splan` названия разведены; статусы и «Ход исполнения» пишет `swork` |
| Малый путь: неясно, что копировать в снимок | Основная сессия называет файлы до правок, они и копируются |
| Четыре противоречия внутри `sbrain` | Гипотеза — о задаче, «сначала узнай» — о решениях; у малого пути одно согласие; правило о `state.md` действует, только когда папка темы уже есть |

Дубли: четыре разошедшихся правила получают один текст — «жди „да“», случай «вики не ведётся», формы файлов вики и передача задания подагенту: везде «дословно, по пути к файлу». Лишнее: уходят три поля, которые никто не читает, двойные формулировки и наслоения в `small.md`.
