# Требования темы chain-cleanup: внутри скила

> R25–R34: места, где `swork` и `sbrain` спорят сами с собой.

- R25. Когда `swork` на малом пути запускает проверяющего, `swork` передаёт задания так, что запреты одного задания действуют только внутри него.
- R26. Когда пользователь выбирает «откатить всё», `swork` удаляет снимок и записи хода этого прогона: повторный запуск начинается как первый.
- R27. Когда `swork` начинает малое изменение, `swork` называет файлы, которые будет править, до первой правки; копии в снимок и поиск правок вне плана идут по этому списку.
- R28. `swork` называет в основном тексте среди своих остановок вопросы, которые задаёт при продолжении прерванной работы.
- R29. Когда `swork` начинает исполнять план впервые, `swork` сверяет строку «Сверено с кодом» с нынешним кодом и называет расхождения.
- R30. Исполнитель среза возвращает в ответе поле для неочевидных фактов и граблей; по нему `swork` пишет заметки.
- R31. `sbrain` называет гипотезу о задаче до первого вопроса, а свои варианты решения — после того, как узнал, что думает и пробовал пользователь.
- R32. Когда `sbrain` ведёт малый путь, `sbrain` спрашивает одно согласие — на показанный короткий дизайн.
- R33. Пока папки темы нет, `sbrain` в вики не пишет; правило «перед остановкой — сначала `state.md`» действует, только когда папка темы уже есть.
- R34. Когда пользователь выбрал следующий шаг, `sbrain` называет, как запустить выбранное, и сам его не начинает.
