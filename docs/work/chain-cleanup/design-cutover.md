# Дизайн темы chain-cleanup: переключение

> Раздел 7, одобрен пользователем 2026-10-12: как два проекта и три профиля переходят на английские скилы.

**Что получает пользователь.** Один шаг по его просьбе после приёмки: оба проекта и три профиля переходят на английские скилы разом.

- **В теме** пишется скрипт смены формата по той же таблице и проверяется на копиях обеих вики. Он меняет строку только на её месте в формате — в заголовке или значении поля, — а не в тексте карточки. Живые вики, профили и `install.sh` тема не трогает.
- **Проверка на копиях.** Английский `check.sh` зелёный; число карточек, строк и ссылок прежнее; каждая фаза и статус — из английского набора таблицы; повторный запуск ничего не меняет.
- **Само переключение.** Сессия спрашивает пользователя, нет ли работающей цепочки в обоих проектах, делает копию каждой вики, запускает `install.sh --mac` и скрипт, проверяет обе вики.
- **При ошибке** вики возвращается из копии, профили — прежней раскладкой.
- **Хвосты.** Отчёт называет, что устарело в личном `CLAUDE.md` пользователя вне блока; правится по его слову. ПК не трогается.

Почему не раньше приёмки: тему ведут установленные русские скилы, а в `rappelz` идёт своя тема — смена формата до переключения оставила бы их без читаемого `state.md`.

Требования: [переключение](requirements-en-cutover.md).
