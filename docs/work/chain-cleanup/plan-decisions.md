# Technical decisions of topic chain-cleanup

> Что выбрал план, вместо чего и почему.

## Technical decisions

- **Стенд без человека — `claude -p` со скилами уровня проекта,** вместо Agent SDK и ручного замера: `--setting-sources project,local` прячет личные скилы и общий `CLAUDE.md`, `--permission-prompts none` убирает меню — скил спрашивает списком, ответ уходит повторным запуском с `--resume`.
- **Вызов сессии стенда** — из папки проекта: `CLAUDE_CONFIG_DIR="${CLAUDE_CONFIG_DIR:-$HOME/claude/personal}" claude -p "<текст>" [--resume <id>] --setting-sources project,local --permission-prompts none --permission-mode acceptEdits --allowedTools <инструменты> --model claude-opus-5-5 --effort xhigh --output-format json`.
- **Ответ этапа — одна постоянная строка,** вместо таблицы ответов. `brain`: ⟦После показа итога: да, на этом остановиться.⟧ `plan`: ⟦Да, одобряю показанное как есть. После показа плана: да, исполнять.⟧ `work` и `seed`: ⟦Принять работу; коммит не нужен.⟧ К каждой дописано ⟦На любой другой вопрос — рекомендованный вариант.⟧ Этап пройден при фазе в `state.md` темы — `требования подтверждены` у `brain`, `план подтверждён` у `plan`, `готово` у `work` и `seed`; с S24 у этих двух — ещё по статусам срезов и записи «этап 7 закончен».
- **Отказ разрешений этап не срывает,** вместо «этап с отказом не пройден»: проверку опасных удалений не снять ни `auto`, ни `--add-dir`, ни песочницей. Этап засчитан по фазе; отклоняются и проверочные команды — S20 называет отказы по этапам.
- **Прогон — две дорожки, подряд:** `brain plan work` на теме `count`, затем `seed` — `swork` продолжает готовую тему `longest` с пятью дефектами; в сквозной прогон дефекты не посеять. Три прогона серии идут одновременно. Повторный запуск пройденную дорожку не трогает, непройденную проходит заново с первого этапа.
- **Форматы судьи.** `key.tsv`: `<метка>⇥<серия>⇥<прогон>`. `verdict.tsv`: `правило⇥<скил>-<N>⇥<да, нет, сомнение или неприменимо>⇥<где видно>` и `посев⇥seed-<N>⇥<найден или не найден>⇥<кем>`. Знак ⇥ — табуляция; ответ — третье поле целиком. С S49 слова ответа — английские, из таблицы.
- **Списки правил — только правила, которые тема не меняет:** 12 + 25 + 25, с S49 — и три правила о языке; новое поведение проверяют строки по тексту. Судье не говорят, где «до»; `saway` не запускается.
- **Судья читает только папку метки** — флаг `--restricted`; путь серии убран из следов в обоих видах.
- **Строки 4, 9 и 14 темы `quality-tokens` исключены из прогона прежних строк:** они требуют дословной сохранности строк, которые тема правит; строка 40 зовёт модель и идёт отдельно.
- **Пометки среза** — строка `- **Пометки:**` карточки среза: `не меняет поведения`, `готовый текст`; вместо угадывания по содержанию.
- **Задание подагенту вырезается командой во временный файл,** вместо «прочитай файл скила»: рядом с заданием ревью лежит «Отсев».
- **Проба усилия — `high`, после серии `en`;** правило остаётся в тексте, только если проба прошла.
