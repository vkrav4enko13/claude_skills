# Requirements of topic chain-cleanup: чтения `splan`

> R35–R43: девять мест `splan`, у которых было два чтения, и чтение, которое остаётся.

- R35. `splan` заводит строки «Фокуса проверки» до остановки перед записью плана; счёт строк проверки, названный на этой остановке, окончателен.
- R36. Где требования молчат о случае, а разумное ожидание есть, `splan` решает случай сам и показывает решение на остановке до записи; пробелом в требованиях `splan` называет только случай, ответ на который меняет объём.
- R37. Когда пользователь отвечает «да» на остановке до записи, `splan` считает одобренным всё показанное на ней: нарезку, точки проверки и решения.
- R38. `splan` называет размер плана и идёт дальше: сообщение о размере — не остановка.
- R39. `splan` пишет в строку проверки команду, которая печатает результат; сравнение с ожидаемым идёт по колонке «Ожидаемое».
- R40. Где пользователь решил принимать результат на глаз, `splan` может сделать сквозную строку проверки ручной; цель плана `splan` берёт из подтверждённой цели темы.
- R41. `splan` называет в плане алгоритм, только когда от его выбора зависит результат сценариев.
- R42. Когда срез правит файл, созданный прежним срезом, `splan` пишет его как «изменить» с пометкой, в каком срезе файл создаётся.
- R43. `splan` называет в «Интерфейсах» имена, которые берёт соседний срез, и тогда, когда срезы правят один файл.

Места в текстах: [аудит — чтения `splan`](../../notes/audit-splan-readings.md).
