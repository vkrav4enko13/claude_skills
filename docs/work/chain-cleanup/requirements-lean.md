# Требования темы chain-cleanup: дубли, лишнее и порядок работ

> R44–R54: у правила один текст, мёртвое уходит, лишние токены и ожидания убраны.

- R44. `sbrain`, `splan` и `swork` называют ожидание ответа в правиле о подтверждении запросом одними словами.
- R45. Правила вики описывают случай «вики в проекте не ведётся» один раз; `sbrain`, `splan` и `swork` на них ссылаются.
- R46. Где сессия запущена во временной папке, а вики в проекте уже есть, `splan` ведёт её по правилам вики.
- R47. `sbrain` держит формы файлов вики в одном файле.
- R48. `splan` и `swork` передают подагенту задание дословно — путём к файлу задания, без перепечатки и пересказа.
- R49. `sbrain`, `splan` и `swork` не пишут в карточки темы и плана строки, которые никто не читает: «Путь», «Проверено» и «Требования подтверждены».
- R50. Каждый скил записывает правило в основном тексте один раз; раздел малого пути `swork` держит по одному пункту на правило.
- R51. `swork` читает файл этапа один раз за прогон и перечитывает его, только если текста файла уже нет в контексте.
- R52. `swork` держит команды PowerShell отдельным файлом и читает его только на Windows.
- R53. `splan` запускает подагентов разведки одним сообщением.
- R54. `sbrain` задаёт вопросы проверки на пробелы одной пачкой, а согласие по разделам дизайна спрашивает одним запросом — по вопросу на раздел.
