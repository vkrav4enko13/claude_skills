> Русские тексты скилов, стенд и файлы фраз лежат копией рядом со стендом: с ней сравнивается перевод, и к ней можно вернуться.

- **Интерфейсы:**
  - берёт: раскладку `$B` из «Общих ограничений»
  - отдаёт: `bash tests/translate/state.sh save|check|restore`; копия `$B/ru-state/<путь от корня проекта>` — русские оригиналы
- **Готовое:** готового нет — искал: `tests/`, `swork/references/snapshot.md` (там копии файлов одного среза, а не состояния целиком)
- **Что сделать:**
  1. `save` копирует в `$B/ru-state/` папки `saway`, `sbrain`, `splan`, `swork`, `tests`, файл `install.sh` и оба файла фраз — `docs/work/chain-cleanup/phrases.sh`, `docs/work/quality-tokens/phrases.sh` — с путями от корня проекта и пишет опись `MANIFEST`: путь и контрольная сумма каждого файла. Папка уже есть — отказ с кодом 1.
  2. `check` сверяет копию с описью: печатает `state: saved`, код 0; расхождение — путь и код 1.
  3. `restore` возвращает из копии каждую сохранённую папку и файл, а файлы, которых в копии нет, из этих папок удаляет; печатает `restored`.
  4. Корень проекта — переменная `STATE_ROOT`, по умолчанию папка двумя уровнями выше скрипта; база стенда — `CHAIN_BASE`, как в `tests/chain/`.
  5. Запусти `bash tests/translate/state.sh save`. `restore` сам не запускай: перевод откатывает пользователь.
  6. Сообщения и комментарии — английские.
