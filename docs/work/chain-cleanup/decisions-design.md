# Решения темы chain-cleanup: план, скорость и замер

> Что выбрано, вместо чего и чьё решение.

- План показывается подробно в чате и файлом-обзором (R1, R2), вместо только чата или «как сейчас» — обзор можно перечитать позже; пользователь знал, что это вторая копия плана; выбрал пользователь; в силе.
- Обзор ведут `splan` и `swork` (R5), вместо одного `splan` — ход виден в одном файле ценой одной правки на срез; выбрал пользователь; в силе.
- Обзор — один файл без предела числа строк (R7), вместо деления по правилу карточки — план читается одним файлом; согласился; в силе.
- «Качество и точность не хуже» — главный критерий, замер по три прогона (R55–R60), вместо двух — «токены можно больше, главное чтобы не пострадало», слова пользователя 2026-10-11; согласился; в силе.
- Мера скорости — замер на стенде до и после (R61), вместо цели в минутах или «без замера» — действие рычагов заранее неизвестно; согласился; в силе.
- Усилие ниже `xhigh` — только исполнителям срезов с готовым текстом и только по замеру (R62), вместо «не трогать» или «пробовать и на проверяющих» — обдумывание занимает 60–70 % времени модели, а у пользователя `medium` однажды вышел дольше `xhigh`; согласился; в силе.
- `/fast` не используется, вместо замера на стенде — скорость берётся оптимизацией самих скилов; выбрал пользователь; в силе.
- Срезы по одному, два проверяющих и порядок «сверка, затем ревью» остаются, вместо одновременных запусков — решения тем `swork` и `quality-tokens` в силе, выигрыш мал, риск для качества есть; согласился; в силе.
