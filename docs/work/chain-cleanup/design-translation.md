# Design темы chain-cleanup: перевод и проверка текста

> Раздел 5, одобрен пользователем 2026-10-12: два прохода, одна таблица соответствий и две проверки.

**Что получает пользователь.** Английский текст, в котором каждое правило на месте, а каждая строка формата названа одинаково везде.

- **Таблица соответствий** — один файл: русская строка, которую скил пишет или читает дословно, и её английская замена. В ней заголовки вики, фазы, статусы, поля карточек, строки шаблонов, слова ответа подагентов, сообщения скриптов. План показывает таблицу целиком; имени вне таблицы не вводится.
- **Словарь терминов** пишется до перевода: у каждого термина цепочки один перевод во всех файлах.
- **Проход 1.** Переводятся правила; строки таблицы остаются русскими, устройство файла — один к одному. Двоякое место переводчик отмечает, чтение выбирает основная сессия и записывает в карточку; спорное идёт пользователю меню.
- **Проверка прохода 1.** Скрипт сравнивает оригинал и перевод: заголовки, пункты, строки таблиц, блоки кода и набор русских строк совпадают. Затем независимый читатель сверяет каждый файл правило за правилом: ничего не потеряно, не добавлено, не изменило силу.
- **Проход 2.** Скрипт меняет строки по таблице в скилах, `check.sh`, заготовках стенда и списках судьи. У строк проверки с русской фразой она заменяется английской из перевода.
- **Проверка прохода 2.** Кириллицы в текстах и скриптах нет; строки проверки обеих тем, `check.sh` и проверки `tests/` зелёные.
- **Предел.** Основной текст каждого `SKILL.md` — не больше 5 000 токенов.
- **Перед переводом** все строки проверки проходят на русском тексте, и русское состояние сохраняется так, чтобы откат вернул тексты, строки проверки и стенд разом. Коммит — только с разрешения пользователя.

Требования: [перевод текста](requirements-en-text.md), [второй проход](requirements-en-pass2.md).
