# Технические решения темы chain-cleanup: перевод

> Что выбрал план для перевода скилов, вместо чего и почему; в конце — два прежних решения, перенесённых из переполненной карточки.

## Технические решения

- **Фразы строк проверки — в файлах `phrases.sh` тем,** вместо правки карточек после перевода: исполнитель в карточки не пишет, а `swork` при каждом продолжении заново запускает проверки готовых срезов — фраза меняется в том же срезе, что и текст.
- **Первый проход — девять порций и девять читателей,** вместо трёх-четырёх больших порций: по 20–42 КБ, чтобы сверка шла правило за правилом.
- **В таблице только закреплённые строки.** Подстановки, подписи меню, заголовки отчётов и формы для чата переводятся в первом проходе: их показывают на языке пользователя.
- **Строка `strict` стоит в оригинале, только когда стоит целым словом,** вместо поиска подстрокой и вместо снятия `strict`: `папки тем` находилась внутри «папки темы» в восьми файлах, а в `wiki-rules.md` она настоящая. Упоминание в другом падеже ловит читатель порции. «Папки темы» — термин словаря `папка темы`: в переводе `topic folder`, а не строка таблицы.
- **`compare.sh` принимает закреплённую строку и русской, и английской:** проверки срезов первого прохода остаются зелёными после второго.
- **Прежние вердикты судьи не правятся,** вместо перевода архива: `verdict.sh` переводит их слова по таблице при чтении.
- **Серию «до» не перемеряем:** прогон `before/3` не доделал `work`, сумма занижена минут на девять; порога скорости у темы нет (R61), S54 называет это рядом с минутами.
- **Русское состояние — копия `$B/ru-state/`,** вместо коммита: `tests/chain/` и `tests/plan-lines.sh` в git не заведены, а коммит — только по слову пользователя.
- **Рабочие файлы перевода — в `$B/translate/`,** вне проекта: в них русские цитаты (R73).
- **Серии на английских текстах — `en`, `en2`, `en3`; имя последней — в `$B/en.current`:** копия скилов в папке серии сама не обновляется.
- **Спорное чтение приходит пользователю остановкой «расхождение»,** вместо ручной строки проверки: остальные места к этому моменту разобраны.
- **Правило судьи о языке — три правила с одним текстом,** `sbrain-13`, `splan-26`, `swork-26`: судья сверяет его на каждом этапе.
- **S54 — последний срез и только проверка, без исполнителя,** вместо правки скорости, новой серии или файла замера в стенде: строить больше нечего, строка 77 — сквозная проверка цели; выбрал пользователь. Порог «быстрее» снят 2026-10-13, слово вердикта приёмку не решает — [заметка](../../notes/chain-speed-en-series.md).
- **Проба усилия (S21) идёт после серии на английских текстах:** она её база.
- **Порядок переключения записан планом** — карточка `cutover.md`: исполнитель в вики не пишет.
- **Формы вики остаются в `wiki-rules.md`,** `wiki-templates.md` удаляется.
- **Мёртвые строки ничем не заменяются;** цель плана `splan` берёт из строки журнала.
