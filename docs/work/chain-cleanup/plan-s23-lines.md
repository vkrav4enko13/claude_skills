# S23. Прежние строки проверки запускаются одной командой

> Все прежние строки проверки обеих тем идут одной командой и зелёные на русском тексте — это мерило для каждого следующего среза.

- **Статус:** готов
- **Закрывает:** R77
- **Зависит от:** S20
- **Файлы:**
  - создать: `tests/translate/lines.sh`
- **Интерфейсы:**
  - берёт: `tests/plan-lines.sh <папка темы> [<номера через запятую>]` — код 0, когда красных строк нет; файлы фраз `docs/work/chain-cleanup/phrases.sh`, `docs/work/quality-tokens/phrases.sh`
  - отдаёт: `bash tests/translate/lines.sh` — печатает `old lines: green` и кончается кодом 0; иначе печатает вывод `plan-lines.sh` о красных строках и кончается кодом 1
- **Готовое:** `tests/plan-lines.sh` — запускает команды строк и пропускает названные номера; свой разбор таблиц не пиши
- **Что сделать:**
  1. `lines.sh` копирует во временную папку карточки `docs/work/chain-cleanup/plan-checks-*.md`, кроме `plan-checks-en-*.md`, и зовёт на ней `plan-lines.sh` с пропуском `2,74,76,77`; затем зовёт `plan-lines.sh docs/work/quality-tokens 4,9,14,40`.
  2. Пропуски: строка 2 сама зовёт прежние строки темы `quality-tokens`; строки 74, 76 и 77 принадлежат поздним срезам; 4, 9 и 14 прежней темы требуют дословной сохранности строк, которые тема правила; 40 зовёт модель, размер проверяет строка 119.
  3. Сообщения и комментарии скрипта — английские.
- **Проверки:** строка 82
