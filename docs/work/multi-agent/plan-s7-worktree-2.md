# S7. agents.sh: worktree, sync and merge — part 2

> What to do in S7: the snapshot, the worktree, submodule clones, the sync, the merge, the fallback to the shared mode and the test.

## What to do

1. **Header.** List `wt`, `sync`, `merge`, `drop`, code 4 and code 5 "use the shared mode" with its `shared:` reasons, and the new records `wt/<id>/`, `waits.tsv` (written in S8), `orphans/` (S8), `attributes`. `merge` takes the essence like `done` and no files; `wt`, `sync`, `drop` take no files. While the mode is off (S12) `wt`, `sync`, `merge` print `agents: off` and exit 5, `drop` exits 0; nothing is created.
2. **Mode test `wt_mode`** — `mode_now` (S12) is `shared` → `shared: mode file says shared`, code 5; `auto` or `worktree` → code 5 with the first failing reason unless all hold: `git -C "$ROOT" rev-parse --show-toplevel` succeeds (`not under git`) and equals `$ROOT` (`root is not the git top level`); `git --version` is 2.40 or newer (`git older than 2.40`). Submodules and a wiki above the root are no reason. Every one of `wt`, `sync`, `merge` runs it first.
3. **`snap <dir>`** — a commit of `<dir>` as it is, without touching the real index: a persistent index per agent and per folder — `.agents/index/<id>-root` for the shared folder, `.agents/index/<id>-wt` for the worktree — seeded once from `git -C <dir> rev-parse --path-format=absolute --git-path index` when that exists, so the stat cache survives between snapshots; `GIT_INDEX_FILE=<that index> git add -A -- . ':(exclude,glob)**/.swork*' ':(exclude,glob)**/.swork*/**'` (no `.agents` exclude: `.agents/` is ignored through `.git/info/exclude`, written by `on`, and an exclude of an ignored path makes `git add` exit 1) plus `':(exclude)<path>'` for every path of `subs`, `git write-tree`, `git -c user.name=agents -c user.email=agents@local commit-tree --no-gpg-sign -m agents-snapshot`, with `-p HEAD` only when `git rev-parse -q --verify HEAD` succeeds; prints the commit id. `subs` — the paths of the entries of mode 160000 in `git -C "$ROOT" ls-files -s`.
4. **`wt`** — under the lock: if `.agents/wt/<id>` exists print it and exit 0; else `S=$(snap "$ROOT")`, `git worktree add --detach .agents/wt/<id> $S`; clone every ignored entry of `git status --ignored --porcelain` (`!! ` lines) except `.agents/` and `.swork*` with `cp -cR`, falling back to `cp -R`; for every path `p` of `subs`: `rmdir <wt>/<p>`, `cp -cR "$ROOT/<p>" "<wt>/<p>"` (fallback `cp -R`), `rm -rf "<wt>/<p>/.git"` — read-only clones, never merged; print the absolute path. A failing `git worktree add` → `shared: worktree add failed`, code 5. The `.agents/` line of `.git/info/exclude` is written by `on` (S12).
5. **Attributes** — write `.agents/attributes` on every `sync` and `merge`: only when `command -v mergiraf` finds it: `*.js *.ts *.jsx *.tsx *.json merge=mergiraf`; no `union` lines — wiki cards never go through a merge (R26). A `.gitattributes` of the project that sets `-merge` wins; that is accepted. Every merge-tree call gets `-c core.attributesFile=<root>/.agents/attributes -c merge.conflictStyle=diff3`, plus `-c merge.mergiraf.name=mergiraf -c 'merge.mergiraf.driver=mergiraf merge --git %O %A %B -s %S -x %X -y %Y -p %P'` when installed.
6. **`sync`** — `B` = the worktree HEAD; `S=$(snap "$ROOT")`; `A=$(snap <worktree>)`; `git merge-tree --write-tree --merge-base=$B $S $A`; the first line of the output is the result tree, written into the worktree by `git -C <wt> read-tree -u --reset <tree>` and HEAD moved by `git -C <wt> update-ref --no-deref HEAD $S`, so the worktree's files equal the result and its own unmerged edits show as the difference against HEAD; exit 0 → code 0; exit 1 → the tree holds the diff3 markers: the same two commands, then `conflict: <path>` per path of a second `git merge-tree --write-tree --name-only --merge-base=…` run (the lines after the first, up to the first blank line), code 4; exit 128 → `shared: merge-tree failed`, code 5. After the read-tree refresh every submodule clone: `/usr/bin/rsync -a --delete --exclude=.git "$ROOT/<p>/" "<wt>/<p>/"`.
7. **`merge "<essence>"`** — `A=$(snap <worktree>)`; `A` tree equals HEAD tree → `merged: nothing`, code 0. Else loop: take the lock, `S=$(snap "$ROOT")`, run merge-tree with base HEAD of the worktree, ours `S`, theirs `A`. Exit 1 → unlock, do as `sync` on conflict, code 4. Exit 0 → paths = `git diff-tree -r -z --name-status $S <tree>`, without entries of mode 160000 and paths under a path of `subs`; fill the `files` array with those paths and run `owners`: a dead owner's claim is handled as `abandoned:` (S8), a live one → unlock, wait 2 s, loop, at most 540 s in all (`AGENTS_MERGE_FOR=<s>` shortens it, for the test), then code 3 `busy: <path> held by <name>` — call `merge` again; run `$AGENTS_BEFORE_WRITE` if set, on the first pass only; any path whose file no longer hashes to its blob in `S` (or exists while absent from `S`) → unlock, loop (R20); else per path: with `--base <snap>` — a path absent from the shared folder is appended to `<snap>/new-files.txt` unless listed, an existing one is copied with `cp -p` to `<snap>/base/<path>` unless that copy exists; keep the old content in a temp copy, write `git cat-file --filters --path=<path> <blob>` with the blob id of `<tree>:<path>` (or delete for `D`), honour the mode of `diff-tree` (exec bit, symlink), `log_diff` it with the essence (R23), print `merged: <path>`; unlock; then `sync` the worktree onto the new shared state. Exit 128 → `shared: merge-tree failed`, code 5.
