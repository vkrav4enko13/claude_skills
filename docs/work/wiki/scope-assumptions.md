Допущения:

- Случая, когда записи не хватило, пользователь не назвал: вики строится на будущее, а не чинит известную поломку.
- Карточки фактов и решений нужны: на прямой вопрос об этом ответа не было, вывод сделан из «делай как wiki».
- Числа в R3–R7, R12 и R71 — оценки по образцу и найденным практикам, без замеров; первая настоящая работа может их поправить.
- Запись в обычной сессии (R14) держится на правиле в инструкциях; механизма, который бы её гарантировал, нет.
- «Что-то изменила» в R14, R15 и R22 понимается широко: изменены файлы проекта либо то, чем проект управляет, — например, настройка ПК по SSH из папки её скриптов. С пользователем это не разбиралось.
- Записи пишет модель. По найденным данным (arXiv 2602.11988) файлы контекста, написанные моделью, помогают слабее написанных человеком; защита — R12, R20, R21.
- Источники из сети читали подагенты через инструмент выжимок; часть цифр — из одного испытания или из замеров самих производителей.
- Файл общих инструкций есть только у личного профиля Claude на Маке; у остальных пяти профилей его нет (проверено 2026-10-10). Что Codex читает `~/.codex/AGENTS.md`, известно по его документации, запуском не проверено.
- На ПК bash есть в `C:\Program Files\Git\bin\bash.exe`, но не в PATH; знаки он считает верно только с заданной локалью (проверено 2026-10-10).
- Утверждения этого документа о проекте проверены автором по выводу команд в той же сессии; независимой проверки подагентом не было.
- Раздел дизайна о скилах одобрен ответом на вопрос о времени записи, без отдельного «верно»; затем подтверждён сводкой.
- Пользователь ожидает, что первой будет сделана сама вики с правилом для любой сессии: она полезна и до переделки скилов.
