# Дизайн темы wiki: скилы, скрипт, установка, перенос

> Что скилы кладут в папку темы и как ловятся сбои записи.

**Скилы пишут в вики** — R28–R44.

```
docs/work/<тема>/
  00-index.md         карточки темы и строка «Требования подтверждены: дата, цель одной фразой»
  state.md            фаза, путь, следующий шаг (R29)
  requirements.md     требования R1… по R45; сверх предела R3 делится по темам
  decision-<имя>.md   решение (R35)
  plan.md             шапка плана: цель, сверено с кодом, решения, не делаем
  plan-checks.md      строка на требование: сценарий, команда, ожидаемое, срез, результат (R55)
  plan-s<N>-<имя>.md  срез
```

Образцы требований — R45–R48; приёмы — R49–R56.

**Скрипт, установка, перенос** — R57–R70. Сбои: забытая запись в обычной сессии видна только по отсутствию строки R20; устаревшая запись ловится по R21; неработающий скрипт — по R61.
