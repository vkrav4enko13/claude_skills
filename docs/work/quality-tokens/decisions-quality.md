# Решения темы quality-tokens: качество и остановки

> Что выбрано, вместо чего и чьё решение.

- Мера цепочки: качество — нет лишнего кода, готовое переиспользуется, — затем токены, скорость последней, вместо «быстрее и дешевле» — слова пользователя 2026-10-11; выбрал пользователь; в силе.
- Перечень готового в плане и у исполнителя (R1–R7), вместо одной строки «поищи готовую» — с перечнем переиспользование 67,8 % против 30,0 %; согласился; в силе.
- Перечень без текста функций, вместо исходника прежних срезов — исходник даёт 29,2 %, как без перечня; согласился; в силе.
- Исполнитель без тестов сверх строк проверки, замеченное — в отчёт (R8–R10), вместо одного запрета «не делай» — лишние тесты едят токены и не меняют результат; согласился; в силе.
- Проверяющий называет прочитанные файлы (R14, R15), вместо веры его отчёту — в 67,9 % прогонов агент читал не всё; согласился; в силе.
- Срезы с общими файлами исполняются по одному, вместо пачки в одном запуске — данные расходятся, а дубли закрывает перечень; согласился; в силе.
- Каждая остановка говорит, что нужно от пользователя (R23–R26), вместо меню без названного шага — «иногда не понятно что надо», слова пользователя 2026-10-11; выбрал пользователь; в силе.
- «Остановиться» в меню — это «Ничего не делать», коммит уходит из меню отчёта (R29), вместо пяти вариантов — в меню четыре места; согласился; в силе. Заменяет варианты из R27 темы `swork`.
