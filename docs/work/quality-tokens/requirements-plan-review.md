# Requirements of topic quality-tokens: проверка плана

> R16, R17: узкое задание проверяющему плана и что остаётся самопроверке.

- R16. Проверяющий плана ищет два вида изъянов: утверждения плана о коде, которые кодом не подтверждаются, и места, где исполнителю придётся гадать.
- R17. `splan` проверяет остальное сам, по списку самопроверки: покрытие требований, порядок срезов, согласованность имён и проверяемость.
