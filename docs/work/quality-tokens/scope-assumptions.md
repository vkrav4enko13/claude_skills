Допущения:

- Замеров на Opus 5.5 нет ни в одном источнике; перечень готового измерен не на моделях Claude. Поведение проверяет только пробный прогон.

- Правила о готовом коде действуют и на малом пути (R7, R12): показано пользователю в сводке, возражений нет.
- Примеров лишнего кода из своих проектов пользователь не назвал: «пока нету проверь сам». Правки строятся по источникам и по прогону темы `wiki`, где правились тексты и bash, а не обычный код.
- Статьи прочитаны подагентами по аннотациям и разделам результатов, не целиком; числа superpowers — замеры автора инструмента.
