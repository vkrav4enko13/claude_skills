# Design темы quality-tokens

> Пять одобренных разделов: план, исполнение, тексты скилов, остановки и сбои.

Одобрен 2026-10-11 одним запросом вместе со сводкой, без правок.

- **План.** Разведка ищет для каждого среза готовый код проекта и записывает его в срез: имя, сигнатура, файл — либо «искал там-то, нет».
- **Исполнение.** Исполнитель получает перечень готового и перечень функций, созданных прежними срезами, без их текста. Возвращает новые функции и замеченное рядом. В конце читают двое: первый ищет недостающее, лишнее и дубли, второй после правок ищет ошибки. Оба называют прочитанные файлы.
- **Тексты скилов.** В основном файле остаются запреты, остановки, вход и указатели, что читать на каком этапе. Порядок этапов уезжает в файлы по этапам; после сжатия контекста указатель говорит, что перечитать.
- **Остановки.** Общий абзац о меню в трёх скилах и три названных места: сводка брейншторма, остановки исполнения, отчёт.
- **При сбоях.** Проверяющий не назвал файл из изменений — файл идёт в отчёт как непроверенный. Пробный прогон не проходит — остановка, решает пользователь.
