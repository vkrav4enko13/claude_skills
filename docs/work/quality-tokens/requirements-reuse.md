# Требования темы quality-tokens: готовый код

> R1–R7: перечень готового кода в плане, у исполнителя и на малом пути.

- R1. `splan` при разведке ищет для каждого среза готовый код проекта, который срез может взять вместо нового.
- R2. `splan` записывает найденное в карточку среза: имя, сигнатуру и файл каждого готового куска — функции, класса или скрипта.
- R3. Если готового для среза не нашлось, то `splan` записывает в карточку среза, где искал, и слова «готового нет».
- R4. Когда исполнитель среза возвращает отчёт, он называет в нём созданные функции: имя, сигнатуру и файл каждой.
- R5. `swork` передаёт исполнителю среза перечень функций, созданных прежними срезами: имя, сигнатуру и файл, без текста функций.
- R6. Исполнитель среза до написания новой функции ищет готовую в проекте; переданный перечень этот поиск не заменяет.
- R7. Где правка идёт без плана карточками, `swork` до правки называет в чате готовый код, который берёт, либо где искал и не нашёл.
