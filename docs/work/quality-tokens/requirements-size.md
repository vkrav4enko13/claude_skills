# Requirements of topic quality-tokens: объём текста скилов

> R18–R22: предел основного текста скила, что в нём остаётся и куда уходит порядок этапов.

- R18. Основной текст каждого из трёх скилов — файл `SKILL.md` — занимает не больше 5 000 токенов.
- R19. Основной текст скила держит раньше порядка этапов правила, которые действуют на всех этапах: запреты, остановки и правило о подтверждениях.
- R20. Порядок каждого этапа после входа лежит в файле `references/`, а основной текст скила называет, какой файл читать на каком этапе.
- R21. Скил после переноса держит каждое правило прежнего текста — в основном тексте или в файле этапа: перенос правил не удаляет.
- R22. Если текста файла этапа в контексте нет, то скил перечитывает этот файл, прежде чем продолжать этап.
