# Решения темы swork: проверка скила

> Что решено при проверке готового скила 2026-10-06 и чьё решение.

Проверка скила, 2026-10-06:

- Перечитать исходные скилы в поисках упущенных приёмов, а не ограничиться таблицей «откуда что взято». Выбрал пользователь.
- Из найденного берутся дефекты самого скила и приёмы, подтверждённые двумя источниками или закрывающие риск проекта Rappelz; приёмы из одного источника отложены (раздел 8). Согласился.
- Мелкое расхождение исполнитель возвращает статусом; правило плана остаётся в пакете. Согласился.
- «Не входит» из требований `swork` сам вставляет в пакет исполнителя и в задание сверки; `splan` не меняется. Согласился.
- Файлы, изменённые между сессиями, показываются списком с одним вопросом, а не дают остановку каждый и не скрываются перестановкой метки. Согласился.
- Перед сверкой проверки всех готовых срезов запускаются заново, каждая разная команда один раз. Согласился.
- Сбой среды — седьмая остановка, а не расхождение с планом и не повод чинить среду самому. Согласился.
- Из поиска несообщённых правок вычитаются файлы только текущего и пройденных срезов. Показано пользователю в сводке, возражений нет.
