# Требования темы swork: исполнение срезов

> R8–R12: порядок срезов, исполнитель с пакетом, его статусы и семь остановок.

**Исполнение срезов**

- R8. Срезы исполняются по одному, в порядке зависимостей. Одновременного исполнения нет.
- R9. Срез плана-файла исполняет свежий подагент. Он получает пакет: свой срез, общие ограничения плана, раздел «Не делаем», текст раздела «Не входит» из файла требований, на который ссылается план, технические решения и правило расхождений. Весь план ему не передаётся. План из чата и задачу без плана исполняет основная сессия.
- R10. Исполнитель не меняет файлы вне списка своего среза. Нужен другой файл — он возвращает статус, а не правит. Основная сессия решает по правилу плана: мелкое расхождение (файл переехал, имя изменилось, смысл тот же) — разрешает, снимает копию (R17) и отмечает в плане; иначе остановка.
- R11. Исполнитель не может спросить пользователя. Он возвращает один из статусов: готово; расхождение с планом в виде «ожидал / нашёл / почему важно»; нужен файл вне списка; не смог. Любое расхождение, и мелкое тоже, исполнитель возвращает статусом: план правит только основная сессия. Останавливается и спрашивает основная сессия.
- R12. `swork` останавливается посреди работы и ждёт пользователя только в этих случаях:
  - код расходится с планом не по мелочи;
  - проверка среза не проходит после двух попыток исправить;
  - срез с необратимым действием — до его начала;
  - у среза ручная проверка, а от него зависят другие срезы;
  - найден изменённый файл вне плана, который нечем вернуть (R19);
  - проверка среза проходит ещё до правок, и срез при этом не сделан (R13);
  - проверку нельзя выполнить из-за среды: машина недоступна, служба не запущена, нет входа. Попытки при этом не тратятся.

  При остановке следующие срезы не начинаются.
