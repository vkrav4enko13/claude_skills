Допущения:

- `splan` и исполнение по нему на настоящей задаче ещё не запускались; на вопрос о настоящих случаях недовольства кодом агента пользователь не ответил. Скил строится по лучшим приёмам источников, а не от названной боли.
- Числа — две попытки (R12) и один повторный круг ревью (R26) — оценки без замеров; первый настоящий запуск может их поправить.
- Решения, принятые без разбора с пользователем и показанные ему списком без возражений: повторное ревью по образцу `splan` (R26); проверка среза до правок (R13); исполнитель не спрашивает пользователя (R11); сделанное сверх плана не убирается у среза с только ручной проверкой (R23).
- Запрет исполнителю менять файлы вне списка (R10) — правило в задании, а не техническая преграда. Без git последствия его нарушения не откатываются (R19).
- Встроенные `/code-review` и `/simplify` в папке без git не запускались; их поведение там известно только по документации. На требования это не влияет: `swork` их не вызывает.
- Тексты части найденных в сети скилов (wshobson/agents, oh-my-claudecode, scope-guard и другие) не прочитаны; отзывы пользователей о сравниваемых скилах не найдены. Отбор приёмов — по чтению текстов на 2026-10-06.
