# Требования темы swork: что изменилось и как вернуть

> R17–R21: копии файлов, метка времени, поиск несообщённых правок, откат и папка снимка.

**Что изменилось и как вернуть**

- R17. Перед каждым срезом основная сессия копирует файлы, названные в срезе как изменяемые, в папку снимка и записывает создаваемые файлы в список новых. Механизм один для проектов с git и без него: на git `swork` не полагается.
- R18. «Что изменилось» — это сравнение копий с текущими файлами плюс список новых. Этот набор получают все проверяющие (R20–R24).
- R19. В начале работы ставится метка времени; после каждого запуска исполнителя `swork` ищет файлы проекта новее метки, кроме файлов текущего и уже пройденных срезов, и так находит правки, о которых исполнитель не сообщил. Файлы, созданные сборкой и запуском, не считаются: в git это файлы, которые git игнорирует; без git — папки и расширения, которые `swork` определяет при подготовке (файлы игнорирования проекта, пути вывода из команд проверки, типовой список) и записывает в «Ход исполнения», чтобы пользователь мог поправить. Найденный файл вне плана возвращается из git, только если проект под git и в начале работы у файла не было незакоммиченных правок (их список `swork` записывает при старте). Иначе вернуть его нечем — `swork` останавливается и показывает его.
- R20. Откат — вернуть копию на место, новый файл удалить. Срез с необратимым действием копиями не откатывается: для него действует раздел «Откат» самого среза.
- R21. Снимок лежит рядом с планом и переживает прерванную сессию. Удаляется он, когда пользователь принял работу.
