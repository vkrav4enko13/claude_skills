# Границы темы splan: не входит

> Отложенное и то, что сознательно не делаем.

- `swork` — отдельный брейншторм; он проектируется под формат плана из этого документа и должен соблюдать правило из R2.
- Планы не про код (поездки, тексты, покупки).
- Пересмотр `sbrain` целиком: меняется только его последний шаг (R3).
- Враждебный цикл проверки в несколько кругов и проверка моделью другого производителя (в том числе через `codex`).
- Хеш одобренной версии плана: правило «правка — не одобрение» (R2) закрывает то же самое.
- Отдельный блок намерения в плане: запрет исполнителю править цель, ограничения и «Не делаем» уже есть.
- Таблица крайних случаев отдельным разделом: её роль выполняет фокус проверки (R17).
- Пометки, какие срезы можно исполнять одновременно: не нужны — `swork` исполняет срезы по очереди (R8 требований `swork`).
- Публикация срезов в трекер задач (GitHub, Linear).
- Поиск по прошлым решённым задачам проекта (у `ce-plan` — папка `solutions/`).
