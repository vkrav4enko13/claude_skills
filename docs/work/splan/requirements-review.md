# Requirements of topic splan: проверка плана

> R21, R22: самопроверка плана и отдельный проверяющий агент.

**Проверка плана**

- R21. До показа пользователю план-файл проходит самопроверку: у каждого требования есть срез и сценарий, который это требование проверяет; каждый шаг однозначен; имена и сигнатуры согласованы между срезами; отказы из R17 приписаны; каждый срез помещается в одну свежую сессию исполнителя, а который не помещается — делится. Прямой и короткий итог проходят первые три проверки этого списка; отдельный агент им не нужен.
- R22. Затем план-файл проверяет отдельный агент, не видевший разговора: сверяет план с кодом и требованиями и ищет изъяны. Найденное `splan` исправляет до показа. Если среди находок была блокирующая, агент читает план второй раз — только исправленные места; третьего круга нет.
