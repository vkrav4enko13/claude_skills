# Design темы splan: устройство скила и источники

> Из каких файлов состоит скил и из какого чужого скила взят каждый приём.

**Устройство скила**

`splan/SKILL.md` и справочные файлы, которые читаются на своём шаге: формат плана и задание проверяющему агенту. Размер скила — по необходимости; ориентир — порядок `sbrain`.

**Откуда что взято**

- `ce-plan`: три размера итога, разведка до вопросов, номера требований в единицах плана, отдельный проверяющий.
- superpowers `writing-plans`: карта файлов, блок интерфейсов у среза, фокус проверки, самопроверка, правило «каждая строка что-то решает».
- mattpocock `to-spec` / `to-tickets`: срезы насквозь, зависимости между срезами, рефакторинг вперёд, точки проверки и их показ до записи, показ нарезки до записи.
- BMAD `bmad-build`: срез, который не помещается в сессию исполнителя, делится.
- GSD, humanlayer `create_plan`, OpenSpec, spec-kit: сверка показала, что их приёмы (враждебный проверяющий с уровнями серьёзности, слова-уступки, проверка поправки по коду, «ожидал / нашёл / почему важно», проверка внутри среза, сверка требований и плана) в `splan` уже есть.
