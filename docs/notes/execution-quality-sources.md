# Приёмы качества исполнения: что взято из источников 2026-10-11

> Три правки `swork` и `splan` по чтению источников об исполнении агентами и идеи, от которых отказались.

- **Взято, `swork`.** При продолжении работы проверки готовых срезов запускаются заново — Anthropic, «Effective harnesses for long-running agents»: базовая проверка в начале каждой сессии.
- **Взято, `swork`.** Проверка спорит со срезом или проходит только подгонкой кода — исполнитель останавливается со статусом «расхождение» — ImpossibleBench, arXiv 2510.20270: строгая фраза и право прервать задачу резко снижают подгонку под тест.
- **Взято, `splan`.** У плана есть сквозная строка проверки цели — документация Claude Code «Best practices» и тот же текст Anthropic.
- **Отвергнуто.** Порог требований на срез: довод — перенос вывода «Constraint Decay» (arXiv 2605.06445) о бэкенд-ограничениях, а план `wiki` со срезами по 15–20 требований прошёл. Пользователь не выбрал 2026-10-11.
- **Отвергнуто.** Цель плана в пакете исполнителя и свежий исполнитель на каждую попытку: дороже, довод слабый.
- **Не найдено.** Исследований «EARS → агент исполняет лучше» нет; польза EARS — в том, что из требования напрямую выводится проверка.
- **Проверяющие ошибаются в сторону придирок.** Тот, кого просят искать, находит всегда; верный код бракуется тем чаще, чем больше требуют объяснений и исправлений (arXiv 2508.12358). Отсев находок основной сессией нужен.
- **Не утяжелять.** Anthropic с новыми моделями убрал проверку после каждого этапа и оставил одну в конце: каждая часть обвязки — допущение о слабости модели.
