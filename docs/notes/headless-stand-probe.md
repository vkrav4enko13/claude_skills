# Проба сессии без человека для стенда цепочки

> `claude -p` 2.1.296 со скилами уровня проекта проходит скил с подагентами и без меню; проверено двумя пробами 2026-10-11.

- **Скилы уровня проекта.** С `--setting-sources project,local` сессия видит только `<проект>/.claude/skills/` и встроенные скилы: личных скилов профиля, плагинов и общего `CLAUDE.md` в ней нет. Вход в аккаунт при этом остаётся: профиль даёт `CLAUDE_CONFIG_DIR`.
- **Вызов скила** — строкой `claude -p "/<имя> <аргументы>"`.
- **Вопросы.** С `--permission-prompts none` инструмента вопросов нет: скил задаёт вопрос нумерованным списком и кончает ход. Ответ уходит повторным запуском `claude -p "<ответ>" --resume <session_id>` — контекст и скил сохраняются.
- **Разрешения.** `--permission-mode acceptEdits --allowedTools Bash Read Edit Write Glob Grep Agent Skill`: запись через Bash во временную папку и чтение этого файла подагентом прошли без отказов; отказы видны в поле `permission_denials` ответа.
- **Подагенты** запускаются; их записи лежат в `<профиль>/projects/<проект>/<session_id>/subagents/agent-*.jsonl`, рядом — `*.meta.json`.
- **Усилие.** У инструмента запуска подагентов есть параметр усилия: подагент, запущенный с `high` из сессии на `low`, пишет `effort: high` в свои записи `assistant`.
- **Ответ `--output-format json`:** `result`, `session_id`, `duration_ms`, `duration_api_ms`, `num_turns`, `total_cost_usd`, `usage`, `modelUsage`, `permission_denials`, `subagent_stats`. `result` — только последний текст хода: остальное берётся из записей сессии.
- **Накопительные поля.** При `--resume` поле `duration_api_ms` идёт с начала сессии, а `duration_ms` — за ход: в пробном прогоне `smoke/1` 2026-10-11 ход 2 шёл 15 с, а `duration_api_ms` у него 214 с при 200 с у хода 1. Время модели сессии — поле последнего хода, а не сумма.
- **Записи сессии.** У записей `assistant` есть `timestamp`, `requestId`, `effort`, `message.usage`; один запрос даёт несколько записей: вход у них одинаков, а `output_tokens` у подагентов полон только в последней — считать последнюю запись на `requestId`.
- **Грабли.** Без `< /dev/null` вызов три секунды ждёт ввод. Флага `--max-turns` в справке нет, но строка 40 темы `quality-tokens` с ним проходит.
- **Замечено рядом.** Папка `~/.claude` существует с 2026-10-10 (`backups`, `cache`, `ide`, `sessions`), хотя профиль по умолчанию удалён; пробы её не создавали.
- **Авто-память.** `--setting-sources project,local` её не выключает: сессия стенда получает инструкцию памяти и заводит папку `<профиль>/projects/<проект>/memory/`; повтор в той же папке проекта унаследует записанное. Замечено на пробном прогоне `smoke/1` 2026-10-11: папка осталась пустой.
