# Время прогонов цепочки по этапам

> На `xhigh` 60–70 % времени модели — обдумывание; подагенты `swork` идут строго по очереди; план и его проверка стоят почти поровну.

- **Способ.** Записи сессий лежат в `~/claude/personal/projects/<проект>/*.jsonl`. Пауза между соседними записями основной сессии относится к тому, что её закончило: ответ модели, результат инструмента, уведомление подагента, ответ пользователя. Подагенты — файлы в `<сессия>/subagents/`, обдумывание — поле `thinkingDurationMs`.
- **Тема `quality-tokens`: Opus 5.5, `xhigh`, обычная скорость.** `sbrain`: модель 23 минуты, три поиска разом 11 минут, ответы пользователя 6 минут на 7 меню. `splan` до меню одобрения: модель 30 минут, проверяющий плана 23 минуты.
- **`swork` в той же теме.** 54 минуты по часам до конца ревью. Подагенты — 47 минут: восемь исполнителей текстовых срезов 9 минут, исполнитель пробной цепочки 11,5, сверка 9, ревью 16. Сумма их времени равна времени по часам: одновременных запусков не было.
- **Обдумывание.** В основной сессии плана — 53 минуты из 77; у подагентов `swork` — 30 из 47.
- **Усилие.** Все большие сессии и их подагенты шли на `xhigh`. В текстах скилов об усилии нет ни слова: подагент берёт уровень сессии.
- **Лимит.** 2026-10-11 прогон упёрся в лимит использования в 11:46 UTC и продолжился в 13:31.
- **Грабли замера.** Отрезок «между командами» включает всё, что было до следующей команды: `splan` по метке — 53 минуты, до меню одобрения — 30. Подагент, продолженный позже сообщением, выглядит долгим: 128 минут вместо 20.
- Источник: разбор записей сессий 2026-10-11; прежние замеры — карточка `efficiency-measurements.md`
