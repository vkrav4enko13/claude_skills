# Команды снимка swork запускай через bash

> Оболочка сессии на Маке — zsh: она не делит `$VAR` на слова, и цикл по списку файлов из переменной молча идёт по одной «склеенной» строке.

- Команды `swork/references/snapshot.md` написаны для bash. Одна команда на один файл работает и в zsh; цикл `for F in $FILES` — нет.
- Чем кончилось 2026-10-11: ступень `stage-5` не создалась, файл уже был изменён пробой, и вернуть его из ступени было нечем — правку пришлось повторить руками.
- Как делать: циклы по файлам снимка запускай как `/bin/bash -c '…'` либо перечисляй файлы в самом `for`.
- Источник: прогон малой задачи через `swork` 2026-10-11, вывод `cp: … No such file or directory`
