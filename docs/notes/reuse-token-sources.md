# Источники о лишнем коде и расходе токенов: чтение 2026-10-11

> Что нашли три поиска в сети для темы `quality-tokens`: взятое, спорное и то, чего не нашлось.

- **Сжатие скила.** После сжатия контекста Claude Code оставляет первые 5 000 токенов каждого скила, на все — 25 000; тело скила оплачивается на каждом ходу — code.claude.com/docs/en/skills, сверено по странице.
- **Перечень готового.** Без памяти о прежнем коде дубли растут с 13,8 % цепочек на первом ходу до 50,8 % на пятом. Перечень «имя, сигнатура, файл» поднимает переиспользование с 30,0 до 67,8 %, полный исходник — нет. Не на моделях Claude — arXiv 2609.35357.
- **Лишние тесты.** Просьба писать меньше тестов снижает входные токены на 33–49 % без значимой потери решённых задач — arXiv 2602.07900.
- **Отчёт проверяющего.** В 67,9 % прогонов агент прочитал не все файлы, и отчёт это скрывал — arXiv 2609.20812, по аннотации.
- **Проверка плана агентом.** Цикл ревью плана удвоил время и не улучшил план: 5 версий × 5 прогонов — заметки к выпускам superpowers, v5.0.6, сверено по файлу.
- **Слияние ревью.** superpowers v6.0.0 слил два ревью задачи в одно; «почти вдвое меньше токенов» — число для выпуска в целом, замер автора.
- **Спор о проверяющем.** Руководство Anthropic по Opus 5: убрать «проверь подагентом». Советы по Claude Code: свежий проверяющий лучше самокритики. По METR около половины изменений, прошедших тесты, не приняли бы.
- **Сокращать текст опасно.** superpowers v6.2.0: удаление раздела ухудшило поведение — 8 из 10 против 5 из 10.
- **Против двух прежних отказов.** Anthropic советует свежий контекст после двух неудачных исправлений и цель в задании подагенту; неработоспособность нынешнего не доказана.
- **Плейбук Anthropic.** «The AI-native SDLC playbook», 2026-08-21: цепочка `intent.md → spec.md → plan.md` совпадает с нашей; нового два приёма — они в «Отложено» корневого индекса — claude.com/blog/the-ai-native-sdlc-playbook, по выжимке.
- **Не найдено.** Замеров на Opus 5.5; пользы прохода упрощения; пользы таблиц «ловушек»; оптимального числа вопросов.
