# Пробная сводка: тема `count`

Сводка пробного брейншторма для стенда `clean/` из `tests/make-wiki.sh`. Пользователь её подтвердил. По ней `sbrain` пишет тему `count`, `splan` — её план, `swork` его исполняет.

**Тема:** `count`

**Цель:** `count.sh` считает слова в `app.txt`

## Требования

В таком порядке:

1. скрипт печатает число строк `app.txt`
2. на пустом `app.txt` система должна печатать `0`
3. с ключом `-v` скрипт печатает число и слово „слов“ через пробел
4. вывод с `-v` читается с первого взгляда

## Решения

- считаем строки, а не слова через пробел; выбрал пользователь
- вывод с `-v` принимаем на глаз, командой его не проверяем; выбрал пользователь
