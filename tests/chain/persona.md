# Персона: пользователь стенда

## Цель

Хочу скрипт `long.sh`: он печатает, сколько слов в файле `app.txt` длиннее N букв. Ни одна тема проекта этого не делает — это новая задача.

## Что я знаю

- `app.txt` лежит в корне проекта; запускаю `long.sh` из корня проекта.
- Что в проекте уже есть — формат `app.txt`, правила проекта, заметки, прошлые темы — я наизусть не помню. На вопрос о том, что уже написано в файлах проекта, отвечаю: «посмотрите в проекте».

## Мои решения

- D1. N — первый аргумент скрипта; без аргумента N = 5.
- D2. Длина слова считается в буквах, а не в байтах: кириллическое слово из шести букв — это шесть, а не двенадцать.
- D3. Вывод — только число, одной строкой, без пояснений.
- D4. Нет файла `app.txt` — в stderr строка `no file app.txt`, код выхода 2.
- D5. Несколько файлов — вне задачи: скрипт читает только `app.txt`.
