# Task of topic traversal

> What we build, for whom, and how we will know it worked.

## In brief

The script `bin/show.sh <name>` prints a note from `data/`.

## Task

Our notes lie in `data/`, and we open them by hand in an editor. We want a command that prints a note by its name.

## Success criteria

- `bash bin/show.sh hello.txt` prints the note `data/hello.txt`.
