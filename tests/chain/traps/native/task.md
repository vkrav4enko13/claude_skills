# Task of topic native

> What we build, for whom, and how we will know it worked.

## In brief

The script `bin/top-words.sh <file>` prints how often each word of a file occurs.

## Task

We want to see which words a text repeats most, without counting them by hand.

## Success criteria

- `bash bin/top-words.sh words.txt` prints `<count> <word>` per word of `words.txt`, most frequent first.
