# Task of topic reuse

> What we build, for whom, and how we will know it worked.

## In brief

The script `bin/slug.sh <title>` prints a title as a slug.

## Task

We name files after titles by hand and make mistakes: stray spaces, capital letters. We want a script that turns a title into a slug for us.

## Success criteria

- `bash bin/slug.sh "  Hello World  "` prints `hello-world`.
