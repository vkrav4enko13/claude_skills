# Шаблоны вики

Читается, когда заводишь вики или новую её часть. Слова в угловых скобках замени, остальное перенеси как есть. Что куда пишется и какие у файлов пределы — в `references/wiki-rules.md`.

## Корневой индекс — `00-index.md`

```markdown
# <Проект>

> <проект одной фразой>

## В работе

- [<тема>](work/<тема>/00-index.md) — <фаза> — дальше: <следующий шаг>

## Отложено

- <что отложено> — <почему или до чего>

## Разделы

- [Правила проекта](rules.md) — решения и ответы, верные для всего проекта
- [Журнал](journal/) — строка на задачу, файл на месяц
- [Темы](work/00-index.md) — папки тем
- [Заметки](notes/00-index.md) — факты, которых не восстановить из кода
```

«Разделы» называют только существующие части вики. У только что заведённой вики там одна строка — журнал; строка части добавляется, когда появляется сама часть. Списки «В работе» и «Отложено» у новой вики пусты: заголовки есть, строк под ними нет.

## Правила проекта — `rules.md`

```markdown
# Правила проекта

> Решения и ответы, верные для всего проекта: по строке на правило.

- <правило> — ГГГГ-ММ-ДД, со слов пользователя
```

## Журнал — `journal/ГГГГ-ММ.md`

Файл на месяц. В нём только строки записей, без заголовка; новая строка дописывается в конец.

```markdown
- ГГГГ-ММ-ДД · <что сделано> — <зачем> · <ссылки>
```

Ссылки ведут на затронутые карточки и пишутся от папки журнала: `[<заголовок>](../notes/<имя>.md)`. Затронутых карточек нет — строка кончается на «зачем».

## Карточка заметки — `notes/<имя>.md`

```markdown
# <заголовок>

> <суть одной строкой>

- <пункт>
- Источник: <файл:строка, команда или слова пользователя с датой>
```

Пунктов столько, сколько нужно факту; «Источник» — всегда последний.

## Индекс папки — `<папка>/00-index.md`

```markdown
# <Название>

> <суть одной строкой>

## Карточки

- [<заголовок>](<файл>) — <суть>
```

Строка на каждую карточку папки. Вложенная папка называется ссылкой на её индекс: `- [<заголовок>](<папка>/00-index.md) — <суть>`.

## Архив — `<папка>/00-archive.md`

Та же форма, что у индекса папки: `# <Название>`, строка сути, `## Карточки`, строки-ссылки. Заводится, когда в него переносится первая строка.
